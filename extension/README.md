# 방문기록 트래커

Chrome 확장 프로그램. 방문한 페이지의 URL, 제목, 시작/종료 시각, 본문 텍스트 전체를 방문이 끝나는 즉시 `{API 서버 주소}/collect`로 전송합니다.

## 설치 (개발자 모드)

1. `chrome://extensions` 접속
2. 우측 상단 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭 → 이 폴더(`extension`) 선택
4. 확장 아이콘 → "설정 열기" → API 서버 주소(예: `https://your-api.example.com`), 최소 체류시간 입력 후 저장
   - 최소 체류시간: 숫자 + 단위(초/분)로 입력하며, 자주 쓰는 값은 프리셋 버튼(5초/15초/30초/1분/5분)으로 바로 고를 수 있습니다. 이 값 미만으로 머문 방문은 아예 전송 큐에 들어가지 않습니다. 0이면 필터 없음(기본값).
   - 단위와 무관하게 내부 저장값은 초(`minDwellSeconds`)이며, 0.5초 미만 체류는 탭 전환 튐으로 보고 설정과 별개로 항상 제외됩니다.
5. 확장 아이콘 팝업의 "수집 상태" 토글로 언제든 수집 켜기/끄기 가능. 끄면 새로운 방문을 수집하지 않으며, 끄는 순간 진행 중이던 방문도 즉시 종료 처리됩니다.

## 전송 데이터 형식 및 전송 시점

방문이 끝나는 시점(탭 전환/창 포커스 이동/idle 진입/탭 닫힘/다른 페이지로 이동)에 **바로** POST합니다.

```json
POST {API 서버 주소}/collect
{
  "url": "https://...",
  "title": "페이지 제목",
  "startTime": "2026-07-30T12:00:00.000Z",
  "endTime": "2026-07-30T12:03:20.000Z",
  "content": "본문 텍스트 일부..."
}
```

전송이 실패하면(오프라인, 서버 다운 등) 해당 건만 로컬 재시도 큐에 남아 30초마다 재시도합니다. 성공한 건은 큐에 들어가지 않습니다.

## 알려진 제약

- **시크릿 모드**: 사용자가 `chrome://extensions`에서 "시크릿 모드에서 허용"을 직접 켜야만 수집됩니다 (확장 프로그램 코드로 강제 불가).
- **SPA 본문 재추출**: `history.pushState` 기반 라우팅 시 본문을 다시 추출하도록 콘텐츠 스크립트에 요청하지만, 렌더링이 800ms보다 늦게 끝나는 페이지는 이전 본문이 잡힐 수 있습니다.
- **본문은 텍스트만**: 원본 HTML이 아니라 [Mozilla Readability](https://github.com/mozilla/readability)(`Readability.js`)로 파싱한 본문 텍스트(광고/네비게이션/사이드바 등 제거된 기사 본문)입니다. 기사형 콘텐츠가 아닌 페이지(예: 검색결과, 대시보드)는 Readability가 파싱에 실패하거나 빈약한 결과를 줄 수 있는데, 이 경우 `document.body.innerText`로 자동 폴백합니다.
- **API 서버 미구현 상태**: 기본 엔드포인트는 placeholder이며, 실제 서버 URL은 설정 페이지에서 지정해야 합니다.
